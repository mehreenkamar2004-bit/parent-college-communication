# Parent College Communication System

## Project Overview

The Parent College Communication System is a web-based application designed to improve communication between parents and college administrators.

The system allows parents to access information about their children, view attendance and academic results, receive college notices, and submit feedback.

The application provides separate access for administrators and parents.

## Technologies Used

- PHP – Backend development
- MySQL – Database management
- HTML – Page structure
- CSS – User interface design
- JavaScript – Frontend functionality
- XAMPP – Local development environment

## Main Features

### Admin Module
- Admin login and dashboard
- Manage student information
- Manage parent information
- Manage teacher information
- Publish college notices
- Manage attendance records
- View parent feedback

### Parent Module
- Parent login and dashboard
- View college notices
- Check child's attendance
- View academic results
- Submit feedback about their child

## Database

The application uses MySQL to store student, parent, teacher, attendance, notice, feedback, and academic information.

Database name: `parent_college_db`

## How to Run the Project

1. Install XAMPP.
2. Start Apache and MySQL.
3. Copy the project folder into the `htdocs` directory.
4. Open phpMyAdmin.
5. Create the database `parent_college_db`.
6. Import the project's SQL database file.
7. Open the browser and visit:

   `http://localhost/parent_college/`
